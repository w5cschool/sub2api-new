## Design Context

### Users
Developers and small engineering teams in China who need a reliable, direct way to connect their coding workflows to AI models through an API gateway. Their primary job is to get an API key, configure a client such as Codex, and keep building without dealing with provider-specific setup friction.

### Brand Personality
Clear, capable, and reassuring. The product should feel like well-run infrastructure: technically credible but approachable rather than intimidating.

### Aesthetic Direction
The existing detailed product pages retain their information architecture. The visual system is an airy blue-and-violet API gateway palette, with compact controls, soft translucent surfaces, and high legibility. The supplied reference informs the color temperature and page rhythm, but all copy, brand marks, diagrams, and assets are original to OnlyCodex. Dark mode remains supported.

### Design Principles
- Make the first action obvious: enter the console or start using the service.
- Explain technical value in plain, concrete language.
- Use the network visual to communicate reliability, not decoration for its own sake.
- Keep navigation and controls compact so the product promise owns the page.
- Respect reduced motion and preserve contrast in both color modes.
